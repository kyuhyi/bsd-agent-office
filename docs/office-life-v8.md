# 퍼널띵 대표·네온 카페트·반려동물·일상 대사

2026-10-24. v7 작업 중 추가된 요청을 같은 사무실에 통합한다.

## 변경
- 대표의 화면 이름, 인물 선택 접근성 이름, 행동 메뉴, 대화 참여자 표시를 모두 `퍼널띵`으로 변경한다. 기존 리깅 자산과 저장된 캐릭터 ID `kyu`는 유지한다.
- 카페트 10개 모두에 둥근 테두리 네온과 넓게 퍼지는 바닥 빛을 추가한다. 카페트 위치별로 서로 다른 주기·색·밝기를 가지며 6–11초 주기로 부드럽게 변화한다. 추가 그림자 광원 대신 발광 재질로 표현한다.
- 고양이 모카와 강아지 두부를 로컬 3D 도형으로 제작했다. 기존 직원과 같은 장애물 회피 경로를 사용하며, 무작위 목적지로 걷고 달리다가 잠시 멈춰 주변을 살핀다. 발·머리·꼬리 움직임을 포함한다.
- 직원에게 미리 작성한 업무·일상 말풍선을 순차적으로 표시한다. 한 번에 한 명, 약 5.5초만 보인다. 실제 업무 실행 중인 직원에게는 표시하지 않는다. AI가 생성한 실시간 대화나 업무 완료 보고가 아니다.
- 전체 보기의 사무실 중심을 아래로 이동하고 확대 비율을 약 7% 줄여 창밖 배경을 더 드러낸다. 회의·인물 확대는 기존 중심을 유지한다.
- 움직임 정지 버튼으로 네온·직원·반려동물이 함께 멈춘다. 반려동물과 네온은 시스템의 동작 줄이기 설정도 따른다.

## 하네스
- 테스트 먼저 추가하여 미구현 모듈 실패를 확인한 후 구현했다.
- 반려동물 산책 지점 간 모든 경로의 바닥 경계 및 가구 충돌 검사, 말풍선 동시 인원 제한과 실행 중 제외 검사 추가.
- 전체 39개 테스트와 타입 검사 통과.
- 신규 유료 모델 생성·리깅·대사 API 호출 없음. 추가 크레딧 0.

## 주요 파일
- `src/features/pets/`: 반려동물 3D 모델과 이동.
- `src/features/characters/ambient-speech.mjs`: 분위기용 대사.
- `src/features/office/NeonRug.tsx`: 카페트 발광 셰이더.
- `output/office-life-v8*.png`: 최종 브라우저 화면.

## 실제 브라우저 확인
- 배포 빌드 성공, 로컬 HTTP 200, 브라우저 오류 없음.
- 대표 선택 메뉴와 대화 참여자에 `대표 · 퍼널띵` 표시 확인.
- 카페트 10개가 서로 다른 시드로 움직이며, 고양이·강아지가 서로 다른 위치로 이동하는 것을 화면과 좌표로 확인.
- `잠깐 의견 나눌까요?` 말풍선 실제 표시 확인. 화면 캡처: `output/office-life-v8.png`.
- 정지 버튼 적용 후 두 번 읽은 반려동물 위치와 네온 시간이 동일했고 재생 뒤 다시 움직였다.
- 최종 구성에서 관측한 최근 프레임 속도는 약 45.6fps(해당 PC·뷰포트의 일시 관측값).

## 네온 점멸 후속 조정
- 사용자 요청에 따라 상시 밝기 변화 대신 4–8초 간격의 독립적인 점등·감쇠 주기를 적용했다.
- 각 카페트는 매 주기마다 점등 시점, 최고 밝기, 잔광 길이가 달라진다. 낮은 밝기 약 2.5%에서 밝게 반짝인 뒤 서서히 잦아들며, 번지는 빛의 폭도 함께 줄어든다.
- 기존 동작 정지 및 시스템 동작 줄이기 설정을 유지한다. 수정 전 파일은 `output/NeonRug-before-pulse-v9.tsx`에 보관한다.
