# BSD Atelier 3D 개편

- 요청: 기존 원본보다 풍부한 깊이와 사실적인 재질, 고급 가구, 귀여운 캐릭터. 기존 실행 기능 유지.
- 제작: Higgsfield 3D Jutsu / Blender 5.2 → GLB → Three.js. 프로젝트 `37af8dc7-096f-4c1f-9c55-0f8df4b5cb70`.
- 공간: 미터 단위 18.8 × 12.8. 6개 업무석, 라운지, 회의 공간, 리셉션, 커피 바. 뒤와 왼쪽 통창, 천장은 열린 단면.
- 계층: ENV 건축 / PRP 가구 / LGT 조명 / CAM 카메라 / CHAR 캐릭터. 웹 좌표 X,Y,Z와 Blender X,-Z,Y 변환.
- 카메라: 전체 사선 조망, 중심 (0,0,0.5), 직교 뷰. 앞쪽 리셉션, 중간 업무·회의, 뒤 창가의 세 층.
- 재질: 월넛·웜 오크·트래버틴·아이보리 부클레·브러시드 브라스·세이지·테라코타. GLB 호환 기본 재질과 이미지 텍스처만 최종 웹에 사용.
- 빛: 창가의 낮은 따뜻한 햇빛, 부드러운 푸른 간접광, 가구 밑 접촉 그림자, 모니터와 펜던트 조명.
- 동작: 이동 가감속, 관절 회전, 걷기와 착석의 부드러운 전환, 눈 깜빡임과 호흡. 실제 작업 중 동작 연결.
- 검증: 기존 12개 회귀 테스트 + GLB 구조/누락 텍스처/용량 검사 + 데스크톱·모바일 실제 브라우저 + 움직임 전후 확인.
- 자산 품질 기준: 가구가 단순 상자, 식물이 단순 구체로 보이면 미완성. 최종 장면에서 곡면, 소재 차이, 빛과 그림자, 얼굴이 보여야 함.
- 출처: Higgsfield 편집 장면 및 카탈로그. CloudAI-X Three.js 스킬은 프로젝트 로컬 설치, MIT. Blender에서 절차적 셰이더가 GLB로 전송되지 않는 제한을 고려.
