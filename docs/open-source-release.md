# 오픈소스 공개 v1.0.0

2026-10-24 사용자 승인에 따라 MIT 소스 공개, 사용법 영상 배포, Threads 소개를 준비했다.

- 기존 비공개 Git 이력은 로컬 bundle에 보존하고, 공개 이력에서는 타 제작자의 참고 캡처 4장과 개인 생성 계정의 원본 다운로드 주소를 제외한다.
- 기존 파일은 로컬에 보존하며 실행 데이터, 녹화 원본, 인증 관련 파일은 계속 Git 제외 대상으로 유지한다.
- 공개 영상은 133초 / 1080p / 30fps / 실제 로컬 화면 / 한국어 자막 / 사용자 제공 BSD BGM이다. ElevenLabs 무료 음성은 사용하지 않는다.
- 코드 무료 사용과 외부 CLI 계정·구독 비용을 README에서 구분한다. 자산별 조건은 ASSETS.md에 기록한다.
- 과거 제작·설계 문서의 비공개 상태 표기는 그 시점의 기록이다. 현재 배포 조건은 LICENSE, ASSETS.md 및 이 릴리스를 기준으로 한다.

검증: 기존 39개 테스트 통과. 공개 영상 전체 H.264/AAC 디코딩 성공. 기존 Git 이력 텍스트에서 주요 API 키·GitHub 토큰·개인키 패턴 검출 0건. 패턴 점검은 모든 형태의 비밀정보 부재를 보증하지 않으므로 공개 범위도 함께 검토했다.
