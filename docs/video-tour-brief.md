# 로컬 사무실 기능 투어 제작안

- 형식: 1920×1080, 약 120초, 실제 로컬 화면만 사용.
- 추천 구조: 조작을 따라가는 기능별 투어. 대안은 업무 흐름 중심 또는 공간 탐방 중심.
- 스타일: 친근함·명확함·빠른 진행. 현재 화면의 네이비 #172337, BSD 레드 #ec413b, 골드 #d7bc87를 사용하고 Pretendard로 설명한다.
- 화면: 실제 클릭과 상태 변화, 중요 버튼으로 확대 후 결과로 이동. 별도 홍보 이미지나 가짜 UI를 사용하지 않는다.
- 강조: 작동하는 결과물의 펼치기·체크 동작. 대기 시간은 압축하고 실제 대기였음을 명확하게 한다.
- 음성: 한국어 음성+자막 또는 자막만, 사용자 선택 대기. 유료 음성 API는 사용하지 않는다.
- 구현 기준: bangtutorial/bang-motion의 카메라 리그, 단일 타임라인, 영상 레이어 동기화, 프레임 단위 MP4 출력.

|시간|실제 화면과 설명|
|---|---|
|0–9초|3D 사무실 전체, 퍼널띵 대표, 팀별 자리|
|9–18초|직원 목록, 역할, 인포메이션 담당자|
|18–30초|캐릭터 클릭, 대표와 직원 얼굴, 질문 화면과 응답|
|30–44초|업무 지시, Claude/Codex 선택, 분석과 결과물 모드|
|44–58초|보고함, 실시간 상태, 업무 상세|
|58–72초|생성 파일 미리보기, 실제 버튼 조작, 검수·다운로드 위치|
|72–83초|12석 회의실 모이기와 복귀|
|83–92초|캐릭터 이동, 자리 복귀, 전체 보기·확대·정지|
|92–104초|배경 4종, 자동 시간, 낮·밤, 네온|
|104–113초|게임·커피 휴식, 고양이·강아지, 분위기용 말풍선|
|113–120초|CLI 연결과 프로젝트 설정, 전체 사무실로 마무리|

설정 화면에서 개인 경로는 화면 밖으로 두거나 가린다. 계정 비밀값은 녹화하지 않는다. 실제 로그인을 새로 실행하거나 파일 다운로드·검토 승인을 눌러 데이터를 변경할 필요 없이 해당 제어 위치를 설명한다.
