# BSD 원본 자산 적용

사용자 제공 자산을 변경하지 않고 `public/brand/`에 복사한다.

- `bsd-color.png`: 리셉션, 회의 디스플레이, 입구의 밝은 바탕 명판.
- `bsd-symbol-color.png`: 상단 브랜드, 기둥, 대표 캐릭터 이름표.
- `kyu-spritesheet.webp`: 대표 프로필. 원본 격자 8열 × 11행, 1536 × 2288. CSS 위치로 사용하며 원본 파일은 수정하지 않는다.
- 대표 3D 모델: 스프라이트의 파란 야구모자·안경·검은 상의·청바지·열쇠고리 특징을 별도 메시로 모델링. 스프라이트를 자동으로 입체 변환한 결과가 아니다.

로고 원본은 Higgsfield 호스팅 Blender의 외부 이미지 반입 제한 때문에 웹 렌더러에서 평면 데칼로 적용한다. PNG의 투명도를 보존하며 가구와 3D 공간에 배치한다. `.blend` 파일에는 로고 PNG가 포함되지 않으며 최종 웹에서 검증한다.

저녁 도시의 색, 짙은 우드 바닥, 소파 배치, 입구 엘리베이터와 전체 화면 구성을 새 참고 이미지에 맞춘다. 기존 업무 기록과 CLI 연결은 유지한다.
