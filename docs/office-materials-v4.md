# 부드러운 가구 마감과 구역 팻말

2026-10-24 사용자 요청에 따른 기존 사무실 개선. 추가 생성·리깅·유료 CLI 실행 없이 적용했다.

## 구현
- `furniture-materials.mjs`: 원본 PBR 색상·법선·거칠기 맵을 보존한다. 소파·회의/대표 의자는 가죽, 업무 의자는 패브릭으로 구분하여 쿠션의 금속 반사와 날카로운 광택을 낮춘다. 원본 공유 재질은 수정하지 않고 별도 재질을 사용한다. 의자의 금속 다리 영역은 색상 마스크로 구분한다.
- `SoftFurnishings`: 직물 미세 요철, 볼륨 있는 쿠션과 파이핑, 팔걸이에 걸친 주름 담요, 중심이 눌린 비정형 빈백 메시를 추가했다. 소파와 의자의 원본 GLB 전체를 재모델링한 작업은 아니다.
- `BotanicalDetails`: 화분당 곡면 잎 24→48개. 길이·높이·방향·색을 분산하고 외곽 화단에는 덩굴을 추가했다. 잎과 줄기는 인스턴스를 사용한다.
- `ZoneSigns`: 둥근 모서리의 실제 입체 보드, 황동 테두리·기둥, 고해상도 한글 텍스처. 개발팀 2곳, 기획팀, 마케팅팀, 관리자, 회의실, 대표실을 표시한다. 기존 배경 없는 작은 팀명은 제거했다. 브랜드 로고를 추가하지 않았다.
