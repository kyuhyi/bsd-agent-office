# GPT 이미지 → Higgsfield 3D 제작

## 2026-10-24 제작 방향
- 기존 단순 도형 중심 모델은 사용자 원본의 품질 기준을 통과하지 못했다.
- GPT 내장 이미지 생성으로 원본 구도·BSD 브랜드·뉴욕 항구·자유의 여신상을 반영한 기준 이미지를 제작했다.
- `public/environment/gpt-bsd-office-master-v1.png`: 전체 공간과 색감 기준.
- `public/environment/gpt-bsd-office-empty-v1.png`: 캐릭터·도시 배경을 분리한 실제 3D 변환 입력.
- `public/environment/gpt-kyu-a-pose-v1.png`: KYU 정체성을 유지한 리깅용 A 포즈 이미지. 아직 3D 모델이 아니다.

## 이미지 생성 프롬프트 요약
1. 원본의 고각 아이소메트릭 구도와 다섯 업무 책상, 중앙 대리석 회의 테이블, 좌측 게임·계단·라운지, 앞쪽 엘리베이터·리셉션을 유지. 차콜 월넛, 크림 데스크, 주황·청색·녹색 의자, 따뜻한 실내 조명. 넓은 사무실이 화면 대부분을 차지. BSD 로고와 KYU 캐릭터 반영. 창밖 뉴욕 항구와 자유의 여신상. 설명·번호·메뉴는 이미지에서 제외.
2. 첫 이미지의 가구 배치를 유지하고 사람·펭귄·외부 배경과 유리만 제거. 프레임·바닥·가구를 보존한 투명 배경 3D 변환 입력.
3. 원본 KYU의 파란 모자, 검은 안경·셔츠, 청바지·운동화·키링을 유지한 전신 A 포즈. 부드러운 입체 형태와 재질, 캐릭터 한 명만 제작.

## 현재 실행 증거
- GPT 기준 이미지의 Higgsfield 업로드 확인: `53f55782-b0dd-4087-89c5-51824fd74524`.
- Higgsfield 모델 목록에서 이미지→3D 모델을 확인했으나 현재 연결에는 `generate_3d` 도구가 없어 공식 웹 제작 화면을 사용했다.
- 기존 3D 프로젝트: `37af8dc7-096f-4c1f-9c55-0f8df4b5cb70`.
- 기존 장면을 보존하고 두 번째 이미지에서 독립된 텍스처 GLB 1개를 생성하도록 요청했다.
- 사용자에게 제시된 30크레딧 1회 생성 승인을 받은 뒤 해당 승인 버튼을 실행했다. 추가 결제·구독 변경·항상 허용은 실행하지 않았다.
- 실제 결과 파일 확인 전 이미지→3D 완료로 표기하지 않는다.

## 하네스
- 16개 테스트 및 TypeScript 검사 통과. 현재 프리미엄 자산 검사는 구버전 모델을 대상으로 하므로 신규 생성 GLB 검사는 별도로 필요하다.
- 브라우저에서 기존 개정 모델을 확인했으며 원본/새 GPT 기준에 비해 디테일·조명 품질 부족. 시각 QA 미통과.
- Claude·Codex 설치 및 로그인 상태는 확인됨. 새 OAuth 로그인 흐름은 이미 로그인된 계정이므로 전체 재인증 검증 전이다.
- 승인 대기 화면 증거: `output/higgsfield-3d-approval.png`.

## 승인된 1회 생성 결과
- 공식 제작 화면의 완료 응답과 GLB 파일을 확인했다. 추가 생성은 요청하지 않았다.
- 서비스 응답의 모델명: Tripo H3.1 Image to 3D. 승인 화면은 30크레딧이었으며 완료 응답은 9크레딧이라고 안내했다. 실제 차감 장부는 확인하지 않았으므로 9크레딧 차감을 확정하지 않는다.
- 파일: `public/models/bsd-gpt-tripo-v1.glb`, 44,246,008바이트, 정점 752,225개, 삼각형 1,400,396개.
- 단일 메시이며 색상·금속/거칠기·노멀 텍스처 3장이 GLB 안에 포함됐다. 원래 가구가 개별 편집 가능한 모델은 아니다.
- 3D로 확인한 후 실제 화면의 환경 모델로 연결했다. 원본 생성 파일은 변경하지 않았다.
- 25배 크기로 정규화하고 위쪽 시점에서 실제 책상/회의 좌석 위치를 측정해 경로에 반영했다. 바닥에만 차콜 색상 보정 셰이더를 적용했다.
- 뉴욕 배경은 실내 렌더 조명의 색 변환을 받지 않도록 분리하고 자유의 여신상이 창밖에 보이도록 위치를 조정했다.
- 캐릭터는 기존 관절형 3D 모델이다. 새 KYU A 포즈 이미지를 리깅한 모델이라고 주장하지 않는다.
- 새 생성 모델 검사와 기존 캐릭터 검사 대상은 분리했다. 기존 캐릭터 검사는 현재 사용하는 `bsd-new-york.glb`를 대상으로 한다.
- 배포용 빌드 성공, 17개 검사 통과. 로컬 배포용 서버 주소: http://127.0.0.1:43140/ .

## 남은 시각 품질 문제
- GPT 기준 이미지와 비교해 식물·소품·의자와 책상 모서리가 뭉개지고, 로고 일부가 텍스처에 왜곡되어 생성됐다.
- 전체 이미지 1회 변환만으로 원본 수준의 정밀한 가구와 캐릭터를 복원하지 못했다. 원본 수준 시각 QA는 미통과다.
- 현재 GLB는 단일 메시이므로 분리된 가구 제작/교체가 필요하다. 추가 유료 생성이나 캐릭터 리깅 비용은 승인되지 않았고 실행하지 않았다.
- Claude·Codex의 로그인 상태와 연결 UI는 확인됐다. 업무 생성은 별도 결과 폴더에 파일을 만드는 방식이며 원본 프로젝트를 직접 수정하고 빌드까지 수행하는 자율 개발 기능은 아니다.
