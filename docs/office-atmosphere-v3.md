# 사무실 소품 밀도와 조명 보강

2026-10-24 사용자 요청: 원본처럼 풍성한 가구·소품 배치, 따뜻한 조명과 입체적인 그림자. 기존 개별 GLB를 유지하며 추가 생성 크레딧은 사용하지 않았다.

## 구성
- `DecorDetails`: 유리문 냉장고, 커피 수납장, 다트 보드, 주크박스, 플로어 램프, 외곽 랜턴, 책·필기구·노트·보드 메모. 오락기 화면의 메시 내부 겹침도 수정했다.
- `BotanicalDetails`: 곡면 잎과 줄기를 실제 메시 인스턴스로 구성하고 외곽 4곳에 월넛 화단을 배치했다. 기존 생성 식물도 함께 사용한다.
- `AssembledOffice`: 좌석별 듀얼 모니터, 데스크 매트, 팀별 네이비·테라코타·올리브 의자. 휴게실과 입구에 러그를 추가했다.
- `Atmosphere`: 회의·라운지·대표석·게임·입구에 따뜻한 실제 광원을 배치했다. 기본 환경광은 낮추고 창가의 차가운 보조광과 대비시켰다. 기둥 벽등과 펜던트의 실제 발광도 보강했다.
- 실시간 PCF 방향 그림자는 이동하는 직원과 가구에 적용한다. 가구 아래 넓은 접촉 차폐는 저비용 공유 텍스처로 보조한다. 경로 추적이나 전체 화면 SSAO를 사용한 결과는 아니다.
- `StaticDetails`: 정적인 소품을 재질별로 병합하고 식물 잎은 인스턴스를 유지하여 호출 증가를 제한한다.
- 화면 비율에 따라 전체 보기의 카메라 높이·중심·확대를 조절해 넓은 화면에서 후면 기둥과 전면 바닥의 잘림을 줄였다.

## 하네스
- 수정 전 백업: `output/before-density-lighting-v3.zip`.
- 실제 가구 위치에 맞게 장애물 목록을 수정했다. 여섯 직원의 자리↔회의 경로와 자리↔휴식·휴식→회의 경로를 검사한다. 직선 구간도 10등분해 가구 관통을 확인한다.
- `npm test`: 24개 통과.
- `npm run build`: 타입 검사 포함 통과. 브라우저에서 여섯 직원이 회의 좌석에 도착해 `seated` 상태인 것을 확인했다.
- 화면 진단에 최근 180프레임의 평균을 추가했다. 로딩을 포함한 누적 평균과 별도로 판단한다.
- 최종 화면과 실행 검증은 `output/office-atmosphere-v3.png`, `output/office-atmosphere-v3-verification.json`에 기록한다.
