# 배경·생활 동작·12석 회의실

2026-10-24. 기존 조립형 가구와 직원 모델을 유지하며 사용자 요청을 확장했다.

## 구현
- 뉴욕 하버, 마운틴 뷰, 포레스트, 오션 테라스 배경 선택과 저장. 전체 화면 이미지, 흐린 주변 레이어, 하단 마스크를 겹쳐 사진 끝의 수평 경계를 제거한다.
- 한국 시간 기준 자동 조명: 06–08 아침, 08–17 낮, 17–19 노을, 19–06 밤. 30초마다 갱신하고 탭 복귀 시 다시 확인한다. 낮/밤 고정 선택도 가능하다.
- 배경은 정적 사진에 밝기·색감을 적용한다. 실제 촬영 시간별 사진이나 천문 일출·일몰 계산은 아니다. 실내 광원도 시간에 맞춰 조정한다.
- 직원 6명에서 11명으로 확장: 아리아·이안·리아·마일로·나리 추가. 기존 생성 남녀 GLB를 복제하고 의상 색, 역할, 좌석을 구별한다.
- 매 120초 주기로 3명이 게임 또는 커피 휴식을 취하고 자리로 돌아온다. 실제 업무 중, 수동 이동 중, 회의 중에는 자동 휴식을 하지 않는다. 동작 일시정지 시 이동과 휴식 시간도 정지한다.
- 나리는 여성 인포메이션 담당자로 고정한다. 휴식과 회의 이동, 수동 이동 메뉴에서 제외한다. 질문과 업무 지시는 가능하다.
- 회의실은 12석: 긴 변 각 5석, 양 끝 각 1석. 테이블과 러그도 확대하고 경로 장애물을 맞춘다. 대표와 직원 10명이 참석하며 나리는 인포에 남는다. 회의 중 이름표는 직무를 접고 이름만 보인다.

## 구조와 하네스
- 환경 선택·시간 계산: `src/features/environment/`.
- 공유 직원 명단: `src/features/characters/roster.mjs`. UI와 로컬 실행기 역할 검증이 같은 명단을 사용한다.
- 휴식 스케줄: `staff-life.mjs`. 좌석과 장애물: `scene-layout.mjs`. 이동은 기존 충돌 회피 경로를 사용한다.
- 37개 테스트 통과: 시간 경계, 설정 복원, 11명 좌석, 12석 회의실, 인포 상주, 휴식 인원·장소 중복 방지, 왕복 이동 경로 포함.
- 타입 검사 및 배포 빌드 성공. 실제 CLI 결과물 검증은 v6 기록을 보존하며 이번 작업에서는 추가 유료 실행을 하지 않았다.

- 대표와 10명 직원의 회의실 착석, 나리 인포 유지 확인: `output/meeting-v7-verification.json`.
