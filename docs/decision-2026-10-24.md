# 확정한 개발 방향

사용자 답변: 개인용 실제 실행 사무실 / 고급 3D 사무실 + 귀여운 캐릭터.

기존 architecture-proposal.md의 방향 질문은 해결되었다. 이 문서는 원본 조사·제안 문서를 덮어쓰지 않고 결정을 기록한다.

Next.js 15 화면, Three.js 3D 공간, Node 로컬 실행기, SQLite 작업 기록으로 구성한다. 클라우드 서비스가 필요하지 않은 개인용이므로 Supabase와 외부 배포는 이번 로컬 실행에 포함하지 않는다.

처음부터 결과를 확인할 수 있도록 6개 역할과 실제 두 CLI를 연결한다. 새 작업별 결과 폴더를 만들어 원본 프로젝트를 보존한다. 기존 프로젝트 파일 반영과 외부 배포·발송은 포함하지 않는다.

캐릭터는 브라우저에서 직접 렌더링되는 관절 계층을 가진 3D 모델로 만든다. 정적 생성 이미지를 움직이는 모델이라고 표시하지 않는다. 초기에는 코드로 만든 관절 애니메이션을 사용하며, 외부 GLB 자산으로 교체 가능한 컴포넌트 경계를 둔다.
