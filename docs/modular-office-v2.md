# 개별 자산 조립형 사무실

## 사용자 확정 방향
- 사무실 전체 이미지의 단일 메시 변환은 폐기 대상이다. 기존 파일은 삭제하지 않고 보존한다.
- 가구와 캐릭터를 개별 모델로 만들고 원본 배치에 맞춰 조립한다.
- 실내 로고는 인포 데스크 한 곳만 사용한다. 후속 요청에 따라 상단 PRIVATE STUDIO도 사용자 BSD 원본 로고로 교체했다. 생성 가구에는 글자·로고를 넣지 않는다.
- 대표는 뒤쪽 대표 책상에 앉는다. 중앙에 서 있는 대표는 제거한다.
- 팀원 목록과 상세 카드도 사무실과 동일한 실제 3D 모델을 렌더링한다. 다크 차콜 패널을 사용한다.

## 분리 구조
- 외장: 바닥, 창, 기둥, 조명, 엘리베이터, 인포, 빈 보드는 코드로 독립 조립한다.
- 가구: 업무 책상, 사무용 의자, 소파, 회의 테이블/의자, 대형 식물, 대표 책상/의자를 독립 GLB로 관리한다.
- 캐릭터: 대표, 남성 직원, 여성 직원 기본 모델. 피부·의상 변형과 스켈레톤 동작은 자산과 별도 관리한다.
- 텍스트: HTML 또는 원본 한글 폰트 기반 화면 텍스트. 이미지 생성 텍스처에 한글을 굽지 않는다.
- 패널: 한 개의 WebGL 렌더러와 여러 뷰를 사용해 목록 및 상세 캐릭터를 표시한다.

## 비용과 승인
- 2026-10-24 잔액 확인: 240.75크레딧.
- 이전 모델의 잔액 변화: 249.75 → 240.75, 차이 9. 상세 품질 설정은 서비스 응답 간 불일치가 있어 확정하지 않는다.
- 가구 8 + 캐릭터 3 모델의 기본 실측 추정 99크레딧. 고품질 옵션·리깅·클립 비용은 미확정이며 확정 견적이 아니다.
- 사용자 승인: 의자 1개 + KYU 대표 1개, 각각 최대30, 총 최대60크레딧. 리깅·클립·재생성·다른 모델은 미포함.
- 두 작업의 웹 승인 30 버튼을 각각 한 번씩 실행했다. 항상 허용은 누르지 않았다.

## 하네스 및 품질 게이트
1. 각 GLB의 실제 메시·텍스처·경계 크기 검증.
2. 원본 이미지와 개별 자산을 확대 비교해 찌그러짐·구멍·가짜 문자 확인.
3. 통과한 자산만 크기·원점 정규화 후 배치.
4. 좌석과 장애물 좌표 검사 → 브라우저에서 걷기·착석·글자·로고·대표 위치 검증.
5. 테스트와 타입 검사, 빌드, 실제 화면 증거를 분리해 기록.

## 새 입력 이미지
- `public/environment/modular-v2/task-chair.png`: GPT 내장 생성. 참조 사무실의 네이비 직물 의자 하나만, 바퀴·쿠션·팔걸이 분리, 투명 배경, 글자/로고 없음.
- `public/environment/modular-v2/work-desk.png`: GPT 내장 생성. 2인용 아이보리·월넛 업무 책상 하나만, 서랍/손잡이/무릎 공간, 글자 없는 파티션, 모니터/의자/소품 제외.
- 대표 입력: 기존 `public/environment/gpt-kyu-a-pose-v1.png` 재사용.

## 개별 자산 조립 구현 결과
- 기존 전체 사무실 변환 모델은 메인 화면에서 제거했다. 원본 파일은 보존했다.
- 업무 책상, 업무 의자, 회의 테이블/의자, 소파, 대표 책상/의자, 식물은 각각 독립 PBR GLB다.
- 모니터는 화면·베젤·스탠드가 분리된 실제 메시이며 코드/디자인 작업 화면을 표시한다. 키보드 키, 마우스, 커피잔, 스탠드 조명도 별도 메시다.
- 바닥, 창, 기둥, 계단, 커피바, 책장, 오락기, 테이블 축구, 엘리베이터, 인포는 독립 구조로 교체했다. 바닥은 별도 GPT 생성 오크 재질을 사용한다.
- 직원 남녀 기본 모델은 실제 생성 GLB에 로컬 관절/스킨 가중치를 구성했다. 6명은 의상 색을 달리하며 회의 이동·착석·업무 손목 동작을 제어한다. 직원에게 유료 자동 리깅을 사용하지 않았다.
- 오른쪽 팀원 패널도 같은 3D 모델을 별도 뷰포트로 렌더링한다.
- KYU는 +Z 정면 교정 후 Higgsfield Meshy 리깅 1건을 완료했다. 반환 GLB의 스킨 1개, 본 24개, PBR 이미지 3개를 검증했다. 손가락 본은 없으며 손목 단위 동작이다. 대표 책상 뒤에 실제 본을 이용해 앉혔다.
- 코드의 관절 동작은 모션 캡처가 아니다. 원본 영상과 동일한 예술 품질을 보장하는 검증으로 표현하지 않는다.

## 추가 승인과 실제 비용
- 사용자 승인: 가구 7 + 직원 2, 합계 상한174 / KYU 리깅1회 상한30 / 추가 전체 상한204.
- 9종 생성 실제162, KYU 리깅 실제5, 합계167크레딧. 첫 리깅 요청의 필수 설명 누락은 작업 생성 전 검증 단계에서 반려됐고 과금0이었다. 필드 수정 후 실제 작업1개가 제출됐다.
- 확인된 최종 잔액37.57. 승인 직전204.75와 생성167의 차이에서 별도0.18 차감이 있으며 원인은 미확인이다.
- 작업 식별자와 다운로드 출처는 `docs/modular-generation-ledger.json`에 기록했다. 재생성·직원 추가 유료 리깅은 실행하지 않았다.

## 검증
- 타입 검사, 기존22개 테스트 및 실제 KYU 스킨·본·착석 방향 테스트 통과.
- 브라우저에서 직원6명의 회의 좌석 도착과 seated 상태 확인.
- 조립 장면 실측 초기 구간 약50fps, 531회 그리기, 약1,080만 삼각형. 로딩/셰이더 컴파일 시 프레임 저하가 있으며 고성능 데스크톱용 자산 크기다.
- Claude Code / Codex 설치 및 로그인은 로컬 API 재확인. 실제 제공자 실행은 이전 검증 결과이며 이번 시각 변경 중 새 유료 CLI 실행을 추가하지 않았다.
- 결과 생성은 별도 결과 폴더 방식이다. 사용자 프로젝트에 자동 반영하거나 실제 배포를 완료한 것으로 설명하지 않는다.
