# 정사각형 사무실, 실제 제공자 검증, 다크 유리 UI

2026-10-24. 사용자 요청의 기존 운영 방식과 가구 자산을 유지하며 진행한다.

## 구현 및 검증 기준
- 24.3 × 24.3의 실제 정사각형 바닥. 가구를 늘리지 않고 입구와 앞쪽 좌석을 재배치하고 경로 경계를 함께 수정한다.
- 계단 양옆 검은 봉·난간만 제거한다. 창문 프레임과 목재 계단은 보존한다.
- 마케팅 앞 두 번째 개발팀 표지판은 디자인팀으로 변경한다.
- 대화창에 대표 KYU와 선택 직원의 실제 3D 얼굴을 함께 표시하며 각 발화 옆에도 표시한다.
- 로컬 Pretendard Variable을 UI와 3D 팻말에 사용한다. 폰트가 준비된 후 사무실 텍스처를 생성한다.
- 결과·설정·대화·알림·입력창을 공통 다크 유리 테마로 연결한다. 팝업 본문은 16px, 설명은 15px, 제목 28px, 버튼 14px를 기준으로 조정한다. 모바일 팝업은 화면 안에서 스크롤한다.
- 기능 하네스: 기존 테스트에 정사각형 바닥·가구 경계·표지판 중복 검사를 추가. 31개 테스트 통과. 시각 변경은 브라우저 렌더링과 실제 폰트/대비/스크롤 검사로 확인한다.
