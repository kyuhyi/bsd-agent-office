# BSD 에이전시 예제 프로젝트

이 폴더는 사무실의 프로젝트 연결과 기획·검수 흐름을 확인하기 위한 예제입니다.

## 브랜드
- 이름: BSD Studio
- 대상: 웹사이트를 새로 만들거나 개선하려는 소규모 사업자
- 핵심 제안: 기획부터 디자인·개발·운영까지 이어지는 웹 제작
- 대면 포지셔닝: 인하우스 시니어 + 외주 협력 네트워크

## 첫 홈페이지 요구사항
- 반응형 레이아웃
- 대표 프로젝트, 서비스 소개, 진행 절차, 상담 안내
- 문의 제출 전 필수 입력값 검사
- 상담 폼은 시연 상태이며 실제 전송은 연결하지 않음
- 가상의 성과·고객 후기는 사용하지 않음

- 모바일에서도 메뉴와 버튼을 누르기 쉬운가?
- 핵심 제안과 다음 행동이 분명한가?
- 키보드만으로 주요 버튼을 사용할 수 있는가?
